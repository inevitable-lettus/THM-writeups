# TryHackMe Writeups

Methodology writeups for TryHackMe rooms I've completed. Each writeup documents my own approach — enumeration, exploitation, privilege escalation, the dead ends, and how I'd mitigate each issue. The focus is reasoning and methodology, not flags.

## Why this repo
Solving a box is invisible until it's written up. These writeups show repeatable methodology, the ability to communicate findings the way a real assessment report would, and that I understood each box rather than copied a walkthrough.

## Approach
Every room here was solved without a walkthrough first. Notes are taken live during the solve; the writeup follows. Flags and room-specific answers are omitted in line with TryHackMe's policy — the methodology is the point.
